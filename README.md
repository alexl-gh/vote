# Анонімізована система взаємооцінювання (Proof-of-Concept)

Гібридний веб-додаток для проведення анонімного оцінювання всередині академічних груп. Архітектура забезпечує деперсонізацію голосів, можливість збереження проміжного прогресу та підтримку крос-платформеного доступу (смартфони, ПК) без необхідності реєстрації користувачів.
