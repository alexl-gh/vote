# Інструкція з розгортання бекенду (Google Apps Script)

Цей посібник описує процес встановлення та налаштування бекенд-частини системи голосування з локального файлу `vote.apps` у середовищі Google Workspace. Архітектура використовує Google Sheets як базу даних та Google Apps Script як REST API.

## Крок 1. Підготовка Бази Даних (Google Sheets)

1. Створіть нову таблицю в Google Sheets.
2. Створіть три окремі аркуші (вкладки) у цій таблиці і назвіть їх точно так:
   * `Tokens`
   * `Criteria`
   * `Votes`
3. Додайте заголовки стовпців у перший рядок (A1, B1 і т.д.) для кожного аркуша:
   * **Tokens:** `Token`, `UserID`, `Role`, `GroupSize`
   * **Criteria:** `CriterionID`, `Name`, `Description`
   * **Votes:** `VoterID`, `TargetID`, `CriterionID`, `Score`, `Status`

## Крок 2. Імпорт коду бекенду

1. У відкритій таблиці перейдіть у верхньому меню до **Розширення (Extensions)** -> **Apps Script**.
2. Відкриється редактор коду. Зліва у списку файлів за замовчуванням буде відкрито файл `Code.gs`.
3. Видаліть весь стандартний код у редакторі.
4. Відкрийте ваш локальний файл `vote.apps` у будь-якому текстовому редакторі.
5. Скопіюйте весь вміст файлу `vote.apps` та вставте його у редактор `Code.gs`.
6. Натисніть іконку дискети (або `Ctrl+S` / `Cmd+S`), щоб зберегти скрипт. Можете перейменувати проект (наприклад, на "Voting Backend") у лівому верхньому куті.

## Крок 3. Розгортання Web-додатка (Deploy)

Це найважливіший етап, який згенерує публічну URL-адресу для зв'язку з фронтендом.

1. У правому верхньому куті редактора Apps Script натисніть синю кнопку **Розгорнути (Deploy)**.
2. Виберіть **Нове розгортання (New deployment)**.
3. Біля напису "Виберіть тип" (Select type) натисніть на значок шестірні та оберіть **Веб-додаток (Web App)**.
4. Заповніть параметри конфігурації:
   * **Опис (Description):** (опціонально) наприклад, `PoC Release v1`.
   * **Виконати від імені (Execute as):** Обов'язково виберіть **Я (Me)**. *(Це дозволить скрипту записувати дані в таблицю від вашого імені, тому користувачам не потрібні Google-акаунти).*
   * **У кого є доступ (Who has access):** Обов'язково виберіть **Усі (Anyone)**. *(Якщо вибрати інший варіант, браузер заблокує запит через політику CORS).*
5. Натисніть кнопку **Розгорнути (Deploy)**.

## Крок 4. Авторизація скрипта (Оновлення дозволів)

При першому розгортанні Google попросить надати скрипту права на редагування вашої таблиці.

1. Натисніть **Надати доступ (Authorize access)**.
2. Виберіть свій Google-акаунт.
3. З'явиться попередження безпеки: "Google hasn't verified this app". Натисніть **Advanced (Додатково)** унизу зліва.
4. Натисніть **Go to [Назва вашого проекту] (unsafe)** / **Перейти до... (небезпечно)**.
5. Натисніть **Allow (Дозволити)**.

## Крок 5. Підключення до Фронтенду

1. Після успішного розгортання ви побачите вікно з надписом "Web app URL" (URL-адреса веб-додатка).
2. Скопіюйте цю адресу (вона виглядає як `https://script.google.com/macros/s/.../exec`).
3. Відкрийте ваш файл фронтенду (`index.html`).
4. Знайдіть змінну конфігурації та замініть її значення на скопійовану адресу:
   ```javascript
   const API_URL = "[https://script.google.com/macros/s/.../exec](https://script.google.com/macros/s/.../exec)";
